# Changelog

Versions follow `TAMA_VERSION` in `firmware/lib/engine/version.h`; each tag `vX.Y.Z` publishes a release and updates the web flasher.

## 0.1.0 (unreleased)

First public version.

- The full game: four needs, care actions, the play minigame, evolution with branches, three endings, eggs with rarity tiers and rare colours, storage (THE GAP), the Chronicle, Status pages with milestones, streaks, bond and medals.
- Touhou Project theme: 48 species, all animated, each with a rare colour.
- Waveshare ESP32-S3-Touch-AMOLED-1.75 firmware, PC simulator, host tests.
- Web flasher (ESP Web Tools) and esptool script; save backup/restore over USB.
